# Photos de référence du banc `check:image-quality`

Trois photos du **Kodak Lossless True Color Image Suite** (kodim04, kodim13, kodim23), le jeu de référence du
traitement d'image, publié par Eastman Kodak pour un usage sans restriction (http://r0k.us/graphics/kodak/).
Réencodées en JPEG qualité 95.

- `kodak-portrait.jpg` : un visage (le détecteur doit le trouver) ;
- `kodak-landscape.jpg` : un paysage (photo sans visage) ;
- `kodak-parrots.jpg` : des perroquets (photo sans visage, couleurs vives).

Elles servent à caler et à vérifier la mesure de qualité, sans réseau. Elles ne sont jamais servies aux utilisateurs.
