# Accessibility

WCAG AA is the floor, and it is mostly free if the markup is right from the start.

## Semantics first

Use the element that means the thing: `<button>` for actions, `<a href>` for navigation, `<nav>`, `<main>`, `<header>`, `<footer>`, `<section>` with an accessible name. A `<div onClick>` is not a button — it is invisible to keyboards and screen readers.

One `<h1>` per page. Heading levels descend without skipping. Headings describe content, they are not sizing tools.

## Focus

- Never `outline: none` without a replacement. Use `focus-visible:ring-2 focus-visible:ring-accent focus-visible:ring-offset-2`.
- The focus ring must reach 3:1 against its background.
- Tab order follows visual order. No positive `tabIndex`.
- Modals trap focus while open, return it to the trigger on close, and close on `Escape`.
- A "Skip to content" link is the first focusable element on pages with substantial navigation.

## Keyboard

Every interactive element is reachable and operable by keyboard. Dropdowns respond to arrows and `Escape`; tabs to arrows; anything with a hover state has an equivalent focus state. Nothing is hover-only.

## Names and labels

- Every input has a `<label>` tied by `htmlFor`/`id`. Placeholder is not a label.
- Icon-only buttons carry `aria-label`.
- Images: descriptive `alt`, or `alt=""` when purely decorative. Never a filename.
- Errors are tied to their field with `aria-describedby` and announced through `role="alert"`.

## Colour and contrast

The design system's `ink` and `ink-muted` are verified against `surface`. Keep them. Body text needs 4.5:1, large text 3:1, interactive borders and focus rings 3:1. Placeholder text needs the same 4.5:1 as body text.

Never carry meaning by colour alone: status gets a shape, an icon or a word alongside the colour.

## Structure

- Lists are `<ul>`/`<ol>`, tables are `<table>` with `<th scope>` and a `<caption>`.
- `lang` on `<html>` matches the content language.
- Dynamic regions that update without navigation use `aria-live="polite"`.
- ARIA only where semantics fall short. A correct native element beats a `role`.
