# Images de partage

- `template.html` — la mise en page (HTML/CSS).
- `i18n/<langue>.json` — les textes de chaque page.
- `illustrations/<clé>.svg` — le dessin de chaque page.

Aperçu : `http://localhost:3001/og/fr/home.html` (…`.png` pour l'image).
Tout rendre : `npm run og:render -- tmp/og`.

Mode d'emploi complet : [`docs/SEO.md`](../../../../docs/SEO.md).
